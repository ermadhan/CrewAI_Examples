# Foundation Examples

This directory contains foundational single-agent and multi-agent examples using CrewAI.

## Contents

- **[example.py](example.py)**: Single-agent workflow demonstrating task execution and structured JSON outputs with a YouTube Shorts content strategist.
- **[multiagent_example.py](multiagent_example.py)**: Multi-agent sequential research workflow using Exa Search and website scraping tools across 4 specialized agents.
- **[assessment.py](assessment.py)**: Code quality and OWASP security review workflow evaluating code diffs in `code_changes.txt`.
- **[unittests.py](unittests.py)**: Unit test suite for validating the agents, tasks, and tools implemented in `assessment.py`.
- **[code_changes.txt](code_changes.txt)**: Sample pull request / code diff reviewed by `assessment.py`.

Refer to the main [Repository README](../readme.md) for full setup and environment instructions.
